# Faction icons

The chosen emblem for each faction, as SVG on a 256 x 256 viewBox (flat vector shapes, no fonts: scale freely).
`export/<faction>.png` is 1024 px with a transparent background and `export/<faction>.pdf` is vector, for print.
All are generated by `python3 tools/icons/faction_icons.py` (the `FINAL` list), so change the script, not the SVGs.
The alternatives that were not picked are in `docs/icon-proposals/`.

| Faction | Icon | Idea |
| --- | --- | --- |
| Kepler | Capitol Dome | civic dome and colonnade in a laurel wreath (two branches of paired leaves, berries, a ribbon tie) |
| Vostok | Star Fort | the plan of a bastion fort, which is a star: glacis, walls, rampart, parade ground, keep |
| Meridian | Exchange Globe | globe with continents, graticule, gold prime meridian and trade routes, ringed by two exchange arrows on a degree bezel |
| SPACECOM | Peacekeeper Shield | badge with crescent and star, nine stars for the member states, rank chevrons |
| Daedalus | Umbra | black disc with a violet corona and one open eye |
| Rustmoon | Salvage Plate | hand-cut scrap, four rivets, a torch-cut acid-green bolt |
